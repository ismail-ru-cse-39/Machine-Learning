Overleaf setup
1. In Overleaf choose New Project > Upload Project and upload this ZIP.
2. The main file is main.tex and uses the IEEEtran conference template.
3. Replace Student Name and student@example.com with your details.
4. Compile with pdfLaTeX.
5. Verify reported metrics against your final notebooks before submission. The BLE session-level Random Forest result is validation-only; held-out test metrics were not supplied. Confirm the product clustering NMI values against the notebook output.
